Part one

Set up

What you get

Bitwig has no looper device: the clip launcher is the looper. Pacer4Bitwig gives the Pacer the controls, the presets and the feedback to play it with your feet.

PACER Looper
The Bitwig controller extension (Pacer4Bitwig.bwextension). All behaviour lives here, and almost everything is configurable in Bitwig's controller settings.
Looper preset
LOOPS on slot D1. Four loop switches, row navigation, undo, tap tempo, and a one-button looper on FS 1.
FX preset
FX on slot D2. Effects on/off for the instrument you are playing, instrument switching and snapshots, while the looper keeps running.
Pacer Studio
A preset editor that runs in Chrome or Edge, online or installed. It writes both presets, backs up the Pacer, and has an LED Lab and a MIDI monitor.
Command-line tools
In tools/: a read-only backup, the preset generator, a guarded preset writer and a MIDI monitor.

You need

  • Bitwig Studio 6 and a Nektar Pacer connected over USB.
  • Chrome, Edge or Opera on a desktop to write presets with Pacer Studio (it needs Web MIDI with SysEx).

Tested on Windows 11 with Windows MIDI Services, which lets Bitwig, Pacer Studio and the tools share the Pacer's ports.

Install the extension

Once per computer. Bitwig reloads the extension by itself whenever the file is replaced.

  1. Download Pacer4Bitwig.bwextension from the latest release, or build it from source with cd bitwig && mvn -q install.

  2. Copy it into Documents/Bitwig Studio/Extensions. A source build does this for you.

  3. Disable Nektar's own PACER script in Settings › Controllers. It claims the same MIDI port. PACER Looper can take over its Track and Transport presets (see DAW mode).

  4. Add the controller: Settings › Controllers › Add controller › Nektar › PACER Looper, then pick the ports.

    PortInputOutputUsed for
    Port 1PACERPACERBoth presets, LEDs, pedals
    Port 2MIDIIN2 (PACER)MIDIOUT2 (PACER)Only the optional Nektar DAW mode

  5. Check the pop-up. Bitwig shows PACER Looper 0.3.0 ready on MIDI channel 16. No pop-up, or an older version number, means the file did not load.

Added the controller before 0.2?

PACER Looper has two ports since version 0.2. Open its entry in Settings › Controllers and pick the port 2 devices, or remove and re-add the controller.

Put the presets on the Pacer

The presets make the Pacer send what the extension listens for: CC 102–119 on MIDI channel 16. Your other presets stay as they are.

With Pacer Studio

  1. Open Pacer Studio in Chrome or Edge, click the connection pill, then Allow MIDI access.

  2. Choose Templates › Bitwig Looper for D1, or Bitwig FX for D2. Keep the LED strategy on two-colour for now.

  3. Click Send changes. Before the first write of a session Pacer Studio asks you to save a full backup: save it, it is your undo.

Two-colour or multi-colour

Two-colour presets use the Pacer's documented LED behaviour: each switch is on or off, and the extension shows state with blink patterns. Multi-colour presets try to show six colours per switch and are experimental. Start with two-colour; switch once the LED test shows six colours on your Pacer.

Keep off D6

The Pacer never answers read requests for D6, so that slot cannot be backed up on its own.

Prepare a Bitwig project

Loops need tracks to live on, and launch quantization to land on the grid.

  1. Create the loop tracks next to each other, e.g. Loop 1–4. The looper manages 1–6 tracks (setting Loop tracks). Audio tracks take your interface input; instrument tracks work too, and can overdub notes into a playing clip.

  2. Tell the extension where they are if they are not the first tracks: Loop tracks start at track. Hold SW A or SW B to move the loop track window: Bitwig shows where the loop tracks now start, and the position is saved with the project. Bitwig 6 shows a controller's project settings nowhere in its own panels, so the Pacer is how you set them.

  3. Set Launch quantization to 1 bar in the extension settings. That is what makes loops start and end on the grid.

  4. Set the tempo, or tap it with SW D.

  5. Keep the audio buffer low, 64–256 samples. Bitwig compensates recording latency itself.

How you hear yourself

Recommended for guitar and vocals

Dedicated input track

One track per instrument with the interface input, monitoring On and your live effects. Set each loop track's input to that track (post-FX) and its monitoring to Off. You always hear the live sound, loops record what you hear, and arming never changes it. These are the tracks the FX preset controls.

Simplest

Monitor through the loop tracks

Loop tracks take the interface input with monitoring Auto. The looper arms the track it records on; Exclusive arm keeps only the latest one armed, so you hear your input once, through that track's effects.

Synths

MIDI loops

Instrument tracks with input PACER or your keyboard. Arm follows the loop you record, and launcher overdub layers notes into a playing clip.

Playing a Push at the same time

The looper selects the loop track it records on, and a Push follows Bitwig's selection. Pin the Push's track (DrivenByMoss: press Select, then Pin Track), or switch off Select the track on press. The FX preset never changes the selection.

Part two

Play

The looper preset

Select D1 on the Pacer: the display reads LOOPS and Bitwig shows Looper preset. Each loop switch runs one loop track like a looper pedal, the rest of the Pacer moves you around the song.

Three gestures on every switch

Tap
Runs on press whenever timing matters (loops, the one-button looper, tap tempo) or when the switch has no hold action; otherwise on release, so a hold never runs the tap first.
Double-tap
The first tap always runs straight away. A second tap within the Double-tap speed window (0.25, 0.35 or 0.5 s) runs the double-tap action instead of a second tap. Nothing is assigned by default.
Hold
Half a second. Actions that delete loops can ask for 1.5 or 2.5 s (Hold time for clearing actions), so a heavy foot never clears a take.

Smart loop

One switch per loop. What a tap does depends on the slot in the current scene row:

The slot isA tapLED, two-colour
emptyarms the track and records from the next quantization point, or after the count-in off
recordingcloses the loop: stops recording and plays it blinks every beat
playingstops it (or, by setting, mutes/unmutes it, toggles overdub, or does nothing) on, gap on the downbeat
stoppedplays it, and unmutes the track if it was muted flash on the downbeat
waiting, counting incancels fast blink
waiting to stopkeeps it playing fast blink

Loop switches fire on press. A hold therefore runs the tap first, which is harmless with the default hold: whatever the tap started is deleted.

Shaping the loop switches

How many
Loop switches: none, SW 1, SW 1–2 up to SW 1–6, and separately Loop tracks: 1–6. A switch is a loop switch when its number is within both. With None the Pacer becomes a fully custom Bitwig pedalboard, while FS 1 and the row actions still run the loops.
Hold to record
Loop switch mode = Hold to record, release to close: press and hold an empty loop to record, let go to close it, like a punch-in. Let go before recording started and it closes one quantization step after it starts. Loops that already exist keep tap and hold.
Double-tap
Double-tap a loop switch: stop, mute/unmute, clear or undo. Clear turns an accidental record into "never mind".
When not loop switches
SW 1 one-button looper / clear last loop, SW 2 mute all / fade out, SW 3 smart loop on the selected track / clear it, SW 4 next / previous loop track.

Building a performance

One-button looper
The classic single-pedal looper spread over the loop tracks: each tap closes the loop that is recording, or starts one on the first empty track of the row. Hold clears the most recent loop.
Mute, don't stop
Tap on a playing loop = Mute/unmute keeps the clip running silently, so it comes back exactly in time. Mute/unmute all loops makes a break; Solo/unsolo selected loop isolates a layer.
Mute on the one
Mute timing = On the next beat / bar holds a mute until the next beat or downbeat, even if your foot is early. A waiting mute blinks fast; tap again to cancel it.
Count-in
Count-in from a stopped transport = 1 or 2 bars starts the transport with the metronome, counts in and records on the next bar. Tap the same switch again to cancel.
Beat counter
While counting in or waiting to record (amber) and while recording (red), SW A–D show the beat of the bar: A = 1, B = 2, C = 3, D = 4.
Match the first loop
Loop length = Match the first loop of the row: the first loop of a row is free, and its length in bars becomes the length of every later loop in that row, which then close by themselves.
Double and halve
Double selected loop duplicates the clip's content (2 bars become 4 of the same material); Halve shortens the loop to its first half.
Rows as song sections
Each scene row is a set of loops. Record the verse in row 1, tap SW B and record the chorus in row 2, launch rows with SW 6. Duplicate row copies a row with its loops and moves there.
Row names
Names for new rows such as Intro, Verse, Chorus, Bridge, Outro name rows created from the Pacer by position, and notifications show them: Row 3: Chorus.
Fades
Fade out and stop all loops ramps the loop tracks down over the Fade length (1, 2, 4 or 8 bars), stops them and restores their volumes. Fade in the row launches it from silence. Tap again during a fade to cancel.
Status at a glance
Show looper status pops up Row 2: Verse | 1 ▶ (muted) 2 ● 3 ■ 4 –: ▶ playing, ● recording, ■ stopped, – empty. It shows even with notifications off.
Panic
Reset the looper stops every loop, cancels count-ins, fades and waiting mutes, unmutes, unsolos and disarms the loop tracks and turns launcher overdub off.

The FX preset

Select D2: the display reads FX and Bitwig shows FX preset with the instrument you are on. The Pacer becomes a pedalboard for whatever you play through Bitwig, and your loops keep playing.

One preset, many instruments
Switching instrument is one tap on the top row, so you can put the guitar back on the stand and pick up the bass mid-song.
The meaning lives in Bitwig
A switch controls the focused instrument's track remote controls page named Pacer, or, without one, the devices of its chain in order. Changing an effects rack never needs a new preset.
Hands off your selection
The FX preset follows instruments with its own cursor, so it never changes Bitwig's selected track, and neither the mouse nor a pinned Push moves it.

Set up your instruments

  1. One track per live instrument, e.g. Vocal, Guitar, Bass, with the interface input, monitoring On and its effects: the dedicated input track setup.

  2. Optional: add a remote controls page named Pacer to each track and map

    • slots 1–6 to what SW 1–6 switch, such as an effect's mix or a chain's volume. The mapping's range is what the switch toggles between, so delay mix 0–35 % is set up in Bitwig;
    • slots 7–8 to what EXP 1 and EXP 2 move: wah frequency, delay feedback, reverb size.

    Save the track as a preset (Guitar rig, Bass rig, Vocal chain) to bring it to any project.

  3. Assign the tracks: select the guitar track in Bitwig and hold SW A until Bitwig shows Instrument A is now Guitar. Repeat with SW B and SW C.

What an FX switch controls

The track has a Pacer page

Remote controls

SW N toggles remote control N between the two ends of its mapping, and counts as on from the middle of the range. A slot you did not map does nothing, and devices are left alone.

No Pacer page

Devices in order

SW N switches the Nth device of the track's chain on and off. Only top-level devices count, so a container is one device; devices after the sixth are out of reach.

Tap latches, hold is momentary, on the same switch: the effect flips on press with no delay, and if you held the switch longer than half a second it flips back when you let go. That is a delay throw on one word of a vocal.

Snapshots

What is stored
The state of SW 1–6 for the focused instrument: each device on or off, or each remote control's exact value, so a delay mix set to 35 % with a knob comes back at 35 %. Remote controls 7–8 stay with the pedals.
How many
Snapshots per instrument: 2 by default (an A/B pair such as rhythm and lead), up to 4. Saved per project.
Using them
Tap SW D for the next snapshot, double-tap to go back to the first, hold to store the current sound in the snapshot you are on. An empty snapshot changes nothing until you store into it.
Changed since
SW D blinks when you have switched something since the snapshot was recalled or stored.

Instruments

By name
An instrument is remembered by its track name, saved with the project. After renaming a track, assign it again. Instruments are found among the first 64 tracks, group members included.
Safe assignments
Assigning uses Hold time for clearing actions, so choose Long if you tend to rest a foot on a switch.
Swapping guitars
Double-tap the instrument's switch to mute its track while you unplug; its LED blinks until you unmute.
Selecting too
Switch on Focusing an instrument selects its track in Bitwig if you want the mixer and devices to follow.

Expression pedals

Each pedal has a target on each preset, plus a response curve and a range that apply to both.

KindTargets
Bitwig parametersSelected track volume, pan, send 1, send 2 · master volume · selected device remote controls 1–2 · project remote controls 1–2
Focused instrumentRemote controls 1–8 of its Pacer page (FX preset defaults: 7 and 8)
MIDIMod wheel (CC 1) · breath (CC 2) · channel volume (CC 7) · expression (CC 11) · brightness / MPE timbre (CC 74) · channel pressure · pitch bend up (heel centre, toe full up)

MIDI targets go into the note input PACER, on the channel set in MIDI channel for pedal messages (default 1). An instrument only hears them on a track whose input is PACER or All ins, armed or monitoring. The Pacer's display keeps showing CC 116 and 117: that is correct, the extension converts them inside Bitwig.

A parameter target with a linear response and the full range is bound directly, so Bitwig's own pickup behaviour applies. Every other combination is calculated by the extension, and the first move after switching jumps the target to the pedal position.

LED test

Settings › Pacer LEDs › Test the LEDs, or the Test the LEDs action, lights every switch white, red, green, amber, blue and purple for a second each. On a two-colour preset every step just looks on; on a multi-colour preset you should see six colours, which confirms multi-colour mode works on your Pacer.

Other presets and Nektar DAW mode

Your other Pacer presets keep working next to PACER Looper.

Channel 16 is the looper's
PACER Looper only reacts to MIDI channel 16 on port 1. Everything else the Pacer sends reaches Bitwig through the note input PACER: pick it or All ins as a track input to play instruments, or use it for MIDI mapping. Keep other presets off channel 16, where CC 20–69 and 102–119 belong to the looper.
Switching presets
Selecting D1 or D2 tells the extension which preset is active; any other preset leaves it as it was. If the switch functions ever stay on the wrong preset, set FX preset › Active preset by hand.

Nektar DAW mode

Switch on Nektar DAW mode (USB port 2) › Serve the Track and Transport presets and assign port 2. The Pacer's built-in DAW presets then work as they did with Nektar's script.

Troubleshooting

Most problems are a port, a channel or a track input.

SymptomFix
"MIDI input PACER is currently being used"Nektar's own PACER script, or another controller, holds the port. Disable it in Settings › Controllers.
The pop-up shows an older versionBitwig loaded an old file. Replace Pacer4Bitwig.bwextension in Documents/Bitwig Studio/Extensions; Bitwig reloads it.
Switches do nothingIs the Pacer on D1 or D2? Does Looper MIDI channel match the preset (16)? Is port 1 set to PACER?
Switches do the other preset's jobSelect the preset again on the Pacer so it announces itself, or set FX preset › Active preset by hand.

An FX switch does nothingThe track has a Pacer page and that slot is not mapped, or the track has fewer devices than the switch number.
Track and Transport presets do nothingSwitch on Nektar DAW mode and assign port 2 (MIDIIN2 (PACER) / MIDIOUT2 (PACER)).
I cannot find the project settingsBitwig 6 shows a controller's project settings nowhere in its panels (older versions listed them in the Studio I/O panel). They are still saved with the project: set the loop track position by holding SW A / SW B, and assign FX instruments by holding SW A–C on the FX preset.
A setting does not seem to applyMost apply immediately; Looper MIDI channel restarts the extension. Check Bitwig's controller console for errors.
